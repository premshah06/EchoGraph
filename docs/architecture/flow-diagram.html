EchoGraph — system flow

How a document becomes verified knowledge, and a question becomes a cited answer

Two LangGraph pipelines share one knowledge store. Ingestion runs a fixed agent sequence with one conditional loop; querying is a single retrieval + streamed-generation hop. The loop is the part worth understanding — it's what turns disagreement between sources into resolved, ranked knowledge.
