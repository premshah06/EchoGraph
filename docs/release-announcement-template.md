## EchoGraph Launch

We are launching EchoGraph, a multi-agent living knowledge base with:

- contradiction detection and synthesis
- citation-grounded query answering
- real-time graph updates
- responsive 3D visualization UI

### Availability

- API: `https://<your-host>/`
- Frontend: `https://<your-host>/frontend`

### Key Notes

- Demo mode available when OpenAI API key is absent
- Production mode enabled when `OPENAI_API_KEY` is configured
- ChromaDB persistence enabled through volume storage
